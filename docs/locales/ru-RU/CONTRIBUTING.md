# Участие в разработке

**[English](../en-US/CONTRIBUTING.md) | [Русский](CONTRIBUTING.md)**

## Локальные проверки

```powershell
cargo fmt --all -- --check
cargo test --locked
```

Если изменения затрагивают поведение прокси, добавьте или обновите интеграционные тесты в `tests/`.

## Безопасность

Не коммитьте сгенерированные приватные ключи CA, экспорты собранных сессий, логи с токенами или локальные environment-файлы. Репозиторий `.gitignore` исключает типичные выходные файлы TLScope, но перед коммитом все равно проверяйте staged-файлы.
