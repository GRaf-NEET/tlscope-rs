# Политика безопасности

**[English](../en-US/SECURITY.md) | [Русский](SECURITY.md)**

TLScope - локальный отладочный прокси, который может раскрывать plaintext HTTP-трафик, когда включена HTTPS-инспекция. Считайте собранные сессии, локальные CA-файлы и экспортированный JSON чувствительными данными.

## Поддерживаемые версии

Исправления безопасности отслеживаются в ветке `main`, пока проект не начнет публиковать версионированные релизы.

## Сообщение об уязвимости

Если в GitHub-репозитории включены private vulnerability reports, используйте GitHub Security Advisories. Иначе откройте issue с минимальным описанием и не публикуйте секреты, собранный трафик, приватные ключи, токены или exploit details, которые могут немедленно поставить пользователей под угрозу.

## Безопасное использование

- Используйте HTTPS-инспекцию только в контролируемых тестовых окружениях.
- Не коммитьте и не передавайте `TLScope-ca-key.pem`.
- Проверяйте экспортированные сессии перед прикреплением к issues.
- Предпочитайте loopback listeners. Используйте `--allow-external` только в доверенных тестовых сетях.
